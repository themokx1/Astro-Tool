Features

The full list in the order of the six workspaces (⌘1-⌘6), plus Settings and the CLI-only extras.

Guide · CLI · Install · Download

The app's interface is available in both English and Hungarian (Settings ▸ General ▸ Language; switching takes effect after a restart). Below we use the English names, since that's the language of this page.

Home

⌘1

  • Pre-flight checklist: a 4-item checkmark/x check (calibration gaps, tonight's sky, moon interference, when the main target clears 30°); collapses to one "ready to head out" row once everything's fine.
  • Night context rail: a dusk-to-dawn timeline, a cloud row, and a "nearest clear night" link if tonight isn't worth going out for.
  • Repeated lessons: if most of your recent nights had the cooler missing setpoint or the focus drifting, it names it here.
  • "Continue where it matters": your least-collected active project, highlighted, with a one-click open button.
  • Rating reminder: "N nights still have unrated frames" plus "Rate Everything" and "Measure Sensor Profile…" buttons.
  • "Best targets tonight": recommendation rows with an export menu (plan as CSV, copy plan, copy calibration shopping list).
  • "Two rigs tonight": with at least two saved equipment setups, a row-by-row suggestion for which rig suits which of tonight's targets.
  • "Cloudy night, clear task": on a cloudy forecast, points you at missing calibration frames so you can at least catch up on those.

Projects

⌘2

  • Table: Project (target + catalog name), Phase, Nights, Series, Integration, Frames (usable/excluded), Latest, Goal (conditional progress bar), Next (a next-step hint with a tooltip); with search, "New Project…", and "Rate All Projects" toolbar buttons.
  • Row actions: Open Project, New Session…, Review Frames, Results.
  • Project workspace: 5 tabs (Overview, Nights, Series, Results, Notes). Overview holds the target details, filters, sessions, quality, stacks, calibration status, a Panels table for mosaic targets (center/frames/integration/rotation/deficit), the planning stats, and at the bottom a target-history timeline (first light, sessions with integration and FWHM, finished stacks).
  • New Project: catalog search by number or name (in English or Hungarian), with a folder preview.
  • Series: one capture batch within a project's night, sharing the same filter/exposure/setup/binning/gain combination; its own Overview/Frames tabs.

Nights

⌘3

  • Table: Night, Projects, Series, Usable, Integration, Triage; a "Next 30 nights" calendar view with Night, Darkness, Moon, Cloud, and best target windows columns.
  • Night Ribbon (timeline): four bands aligned on a shared time axis: twilight, moon, target, and the actual capture spans with their gaps (e.g. "Capture 21:03-04:12, 2 gaps totaling 41 minutes").
  • Night workspace: 4 tabs (Overview, Series, Frames, Notes). Menu: Open Night, Reveal in Finder, Edit Night Notes…, Open Calibration…, Rate Frames, Open in Insights.
  • Night notes: fixed fields (Bortle, SQM, Seeing, Transparency, Wind, Dew) plus custom keys, with a README-conflict warning.

Planning

⌘4

  • Target recommendation table: free-text search (catalog number or name, English or Hungarian), "Hide non-photographable" and "Useful framing only" filters, a date picker for planning a different night. Columns: Target, Score, Photographable, Frame fill, Moon, Tonight's sky, Framing, Integration.
  • Equipment comparison: a "Compare with" picker (shown once you have at least two saved setups) that compares framing/field of view against another saved setup, shown in the Framing column and under the sky path chart.
  • Sky path chart: an altitude-over-time curve with the culmination point and a moon-separation caption.
  • Season window finder: a monthly visible-hours bar chart with a text summary (e.g. "Season: {range} · peak {date}").
  • Saved targets: your own list with notes, season captions; Note… and Remove (with confirmation) actions.

Library

⌘5

  • Archive map (the section's root): a verdict-sentence header, a clickable byte-usage strip, then a "Needs you" section with 8 finding kinds (stacking leftovers, Finder metadata files, byte-identical copies, calibration in the wrong folder, folder names that break scanning, checksum mismatches, unconfirmable items, not-yet-checked items), plus a per-target "Targets" section. Opening a card shows a hierarchical file table (path, size, reveal in Finder) with either a "Move to Quarantine…" flow or a "no automatic fix" explanation.
  • Never deletes: every file operation moves things to .astro_tool/cleanup_quarantine, never deletes; gated behind typing a confirmation code, and reversible.
  • Calibration: two tables: "Session coverage" (combo/lights/master/sessions, with a "Preview Link…" row action) and "Master darks" (path/temperature/age/status, with a "Show in Finder" row action).
  • Conversion (organize a session): a 3-4 step wizard: choose a session (Logical or Physical mode) → review/edit the detected capture groups → optionally resolve ambiguous files → apply (with an impact summary and confirmation). Turns a raw session folder into named capture groups by exposure/filter/sensor, either database-only or with real file moves.
  • Cleanup: a preview-only candidate list by category, each captioned "Proposed action: move to quarantine, never delete"; footer reads "Preview only, no files moved" with an "Apply Quarantine…" button.
  • Sensor Profiles: per camera/gain/offset combo: bias ADU, read noise e⁻, dark rate e⁻/s, temperature °C, EGAIN, frame count, a staleness badge, and a measurement-history sparkline. "Measure Sensors…" only reads tracked BIAS/DARK frames and only writes to the local index, never to the image library.
  • Import from card: the toolbar's "Import from Card…" action (reachable from both Home and Library) brings a connected card or volume's FIT/CR3 files into the library in 6 steps (Source → Classify → Destination → Preview → Copy → Receipt); it never touches the originals on the card.

Insights

⌘6

  • Period picker and 5 header tiles: Integration, Sessions, Targets, Light frames, Average night.
  • "Year in review": favorite target, light frame count, biggest month, new targets, best-FWHM night.
  • "This month vs. last year": the integration-hours and session-count difference against the same month last year, with an optional best-FWHM delta.
  • Capture efficiency: usable/rejected ratio, efficiency%.
  • Capture quality trends: 3 line charts (FWHM, background, efficiency), per capture, by date; a "Start Measuring" button triggers a real FWHM measurement.
  • Sky brightness vs. moon phase: a 4-band illumination table with a headline sentence (e.g. "reads about Nx brighter under a full moon").
  • Nights leaderboard: the best 5 and worst 5 nights, ranked by a combination of FWHM, efficiency, and background, showing only the raw numbers with no hidden score.
  • Capture activity: a monthly integration-hours bar chart, with a "most photographed" ranking.
  • Filters and passbands, Equipment usage: simple breakdown lists.

Reviewing frames

From a Projects row or workspace ("Review Frames")

  • "Rate Frames…" and "Review Frames…" are two separate actions: the first runs a real quality measurement (native, or native+Siril hybrid), the second opens the blink viewer.
  • Blink viewer: a large-preview, steppable frame viewer (←/→ to page, A accepts, X rejects, U clears the decision), with a Score/FWHM/Roundness/Percentile tile per frame.
  • Triage callouts: a low-altitude warning (if the weakest frames were all shot below 35°) and a satellite-streak suspicion flag, never an automatic rejection.

Global commands

Available anywhere

  • ⌘1-⌘6: jump between the six workspaces.
  • ⌘R Rescan, ⌥⌘A Run Audit (the fast, no-duplicate-scan variant is menu-only, no shortcut), ⌘F Find (the global search popover), ⌘[ Back, ⌥⌘I Show/Hide Inspector.
  • Help menu: Glossary (also reachable from a specific entry via metric-explanation popovers), Folder Structure, First Steps.

Settings

⌘,

  • General: the interface-language picker (System/Hungarian/English; switching takes effect after a restart), and the confirmation rule for write operations.
  • Libraries & Safety: recent libraries, a "scan on open" toggle, enabling write operations, library rules, session-residue patterns (an editable list).
  • Location: site name, latitude/longitude, and a display of what's currently in effect.
  • Planning: the integration baseline references (hours, f-ratio, surface brightness) every Planning score is built on; also where the extended target catalog (SIMBAD/VizieR, on by default) is toggled on or off.
  • Imaging Setups: managing saved camera+optics combinations (the same ones Planning's comparison and Home's "Two rigs tonight" card read).
  • Equipment: actually the filter library (a manufacturer/model/passband table), which feeds Insights' "Filters and passbands" breakdown.
  • Support: the privacy notice, diagnostics generation, and release channel.

CLI-only extras

Most of what used to be terminal-only now lives on a workspace (session organizing moved into Conversion, card import into the Import wizard, calibration linking into Library). What's still terminal-only after that:

  • tag: adds, removes, and lists free-text target- and session-level tags.
  • match: matches a given session's light/flat/dark/bias set and lists the problems it finds.
  • panels: the full, row-by-row WCS-based integration table for a mosaic target's panels (the Projects Overview tab only shows a single summary deficit sentence from the same data).
  • solve: plate-solves targets without coordinates (e.g. wide-field CR3) using Siril.
  • ingest-dss: reads DeepSkyStacker metrics and decisions.
  • export --format csv|md: a generic per-session CSV or Markdown log for a target (the AstroBin CSV export stayed in the app, these two formats didn't).
  • stacklist's full output: the hardlink tree, .dssfilelist, and Siril script generation are terminal-only; the app's "Stack List" button only gives the CSV manifest version of the same data.
  • report / target-report: saving a standalone HTML night or target report to a file.
  • config: printing the currently effective configuration or the path to config.json.
