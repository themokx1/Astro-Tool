Install

Four simple steps from download to first launch. The public release is Developer ID signed and Apple-notarized.

Download · First steps · CLI

Requirements

macOS 26 or later, an Apple Silicon or Intel Mac. The app is free, no account or registration needed.

Installing

  1. Download the DMGget the latest AstroTool-x.y.z.dmg from the GitHub releases page.
  2. Open the DMGdouble-click the downloaded file, which opens a window with the AstroTool icon.
  3. Drag AstroTool into Applicationsin the window that opens, drag the app icon onto the "Applications" shortcut, then close the DMG window.
  4. Launch it from Applicationsthe notarized release opens as a normal app; if macOS asks for confirmation, check that you downloaded the official GitHub release.
  5. Choose the image-library locationAstroTool only asks for access to the folder or volume you select.

Verified release

The checksums for the DMG and command-line ZIP are published in SHA256SUMS.txt beside the release. The release process verifies the app's signature and notarization before upload.

Optional: CLI

The astrotool command-line tool is a separate ZIP on the same releases page (astrotool-x.y.z-macos-universal.zip).

  1. Unzip itdouble-click the ZIP, or run unzip astrotool-x.y.z-macos-universal.zip in Terminal.
  2. Put it on your PATHfor example mv astrotool /usr/local/bin/ (or any directory already on your PATH).
  3. Check it worksastrotool --help in Terminal.
