Install

Five steps from download to first launch. The app isn't notarized yet, so macOS will warn you the first time: here's how to allow it.

Download · Guide · CLI

Requirements

macOS 26 or later, an Apple Silicon Mac (M1 or newer). The app is free, no account or registration needed.

Installing

  1. Download the DMGget the latest AstroTool-x.y.z.dmg from the GitHub releases page.
  2. Open the DMGdouble-click the downloaded file, which opens a window with the AstroTool icon.
  3. Drag AstroTool into Applicationsin the window that opens, drag the app icon onto the "Applications" shortcut, then close the DMG window.
  4. Launch it from Applicationssince the app isn't notarized yet, macOS will block the first launch: see below for how to allow it.
  5. Grant disk access if askedthe app will request permission for the volume your image library lives on: you can revoke this any time under System Settings ▸ Privacy & Security ▸ Full Disk Access.

First launch: Gatekeeper blocks it

AstroTool is a small, independently developed project, not yet notarized by Apple. This isn't a virus warning, it just means Apple hasn't run it through their own automated check yet. Either of the two methods below clears it, and you only need to do this once.

Option A: right-click → Open

  1. Applications folderfind the AstroTool icon (Finder ▸ Applications, or ⌘⇧A).
  2. Control-click (or right-click) the iconchoose "Open" from the menu that appears. Don't double-click, this step only works with a right-click.
  3. Confirmclick "Open" again in the dialog that appears. After this, the app launches normally with a plain double-click.

Option B: System Settings

  1. Try opening itdouble-click AstroTool: macOS shows a "can't be opened" style warning because the app isn't from an identified developer.
  2. System Settings ▸ Privacy & Securityscroll down until you see the blocked-app message about AstroTool near the bottom of the page.
  3. "Open Anyway"click the button, then confirm with your password or Touch ID.

Optional: CLI

The astrotool command-line tool is a separate ZIP on the same releases page (astrotool-x.y.z-macos-universal.zip).

  1. Unzip itdouble-click the ZIP, or run unzip astrotool-x.y.z-macos-universal.zip in Terminal.
  2. Put it on your PATHfor example mv astrotool /usr/local/bin/ (or any directory already on your PATH).
  3. Clear the quarantine flagfor a terminal binary you can lift the Gatekeeper flag directly: xattr -d com.apple.quarantine /usr/local/bin/astrotool. This clears the same flag as Option A/B above, just from the command line.
  4. Check it worksastrotool --help in Terminal.
