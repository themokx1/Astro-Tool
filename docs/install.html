Letöltés · Első lépések · CLI

Rendszerkövetelmény

macOS 26 vagy újabb, Apple Silicon vagy Intel Mac. Az app ingyenes, fiók vagy regisztráció nem kell hozzá.

Telepítés

  1. Töltsd le a DMG-ta GitHub kiadások oldaláról a legfrissebb AstroTool-x.y.z.dmg fájlt.
  2. Nyisd meg a DMG-tdupla katt a letöltött fájlon, ez megnyit egy ablakot az AstroTool ikonjával.
  3. Húzd az AstroTool-t az Alkalmazások mappábaa megnyíló ablakban húzd az app-ikont az "Alkalmazások" parancsikonra, majd zárd be a DMG-ablakot.
  4. Indítsd el az Alkalmazások mappábóla notarizált kiadás normál alkalmazásként indul; ha a macOS megerősítést kér, ellenőrizd, hogy a hivatalos GitHub-kiadást töltötted le.
  5. Válaszd ki a képkönyvtár helyétaz AstroTool csak ahhoz a mappához vagy kötethez kér hozzáférést, amelyet te kiválasztasz.

Ellenőrzött kiadás

A DMG és a parancssoros ZIP ellenőrzőösszege a kiadás mellett található SHA256SUMS.txt fájlban van. Az alkalmazás aláírását és notarizációját a kiadási folyamat még a feltöltés előtt ellenőrzi.

Opcionális: CLI

A parancssoros astrotool eszköz külön ZIP-ben tölthető le ugyanarról a kiadások oldalról (astrotool-x.y.z-macos-universal.zip).

  1. Csomagold kidupla kattintás a ZIP-en, vagy unzip astrotool-x.y.z-macos-universal.zip a terminálban.
  2. Tedd a PATH-bapéldául mv astrotool /usr/local/bin/ (vagy bármelyik, a PATH-adban szereplő mappa).
  3. Ellenőrizdastrotool --help a terminálban.
