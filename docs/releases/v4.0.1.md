# AstroTool 4.0.1

Ez a V4 első hotfix kiadása. A 4.0.0 funkciói változatlanok; a kiadás az
első indítás képkönyvtár-választását javítja.

## Javítás

- A **Képkönyvtár kiválasztása…** gomb ismét biztosan megnyitja a natív macOS
  mappaválasztót.
- A mappaválasztó már nem próbál egy második modális ablakot megjeleníteni az
  onboarding lapja fölött. Az onboarding röviden bezáródik, a bevált natív
  választó megjelenik, majd a kiválasztott képkönyvtár beolvasása az új
  workflow-ban folytatódik.
- A választó megszakítása után az első lépések felülete visszatér.

## Telepítés

1. Töltsd le az `AstroTool-4.0.1.dmg` fájlt.
2. Ellenőrizd a letöltést a mellékelt `SHA256SUMS.txt` alapján.
3. Nyisd meg a lemezképet, és húzd az AstroTool appot az Applications mappába.

Rendszerkövetelmény: macOS 26 vagy újabb. Az alkalmazás és a CLI Universal
bináris. A publikus csomag Developer ID aláírással és Apple-notarizációval
készül.
