# AstroTool 3.0.0-beta.1

Az első V3 béta: minden, ami a stackelés előtt kellhet — behozatal,
kalibráció-előkészítés, biztonságos rendrakás, metaadat-javítás, derült idő
jelzése és az éppen futó éjszaka read-only követése.

## Újdonságok

- Az **ingest-figyelő** felismeri az új felvételi kötetet, és előkészíti az
  importvarázslót. Projektet csak kellő bizonyosságnál javasol, és akkor is
  jóváhagyható mezőként.
- A **kalibrációs automata** homogén forráskészletből Sirillel tud dark
  mastert építeni. A művelet opt-in, külön megerősítést kér, és sosem ír
  felül meglévő fájlt; a flat-hiányt az indulás előtti lista jelzi.
- Az **irányított rendrakó** egyesével vezet végig a találatokon, de ugyanazt
  a visszavonható karanténláncot használja, mint a meglévő Archívum.
- A **metaadat-javító** láthatóvá teszi a felismerési javaslatokat és a kézi
  capture-hozzárendeléseket.
- A **derült-trigger** opcionális helyi értesítést ad a beállított időben.
- Az **élő éjszaka-mód** figyeli a session mappát, mutatja az érkező
  képkockákat, a gyors csillagmetrikát és a célhoz becsült hátralévő időt.

## Biztonság és korlátok

- Az AstroTool továbbra is read-only módban indul. Másolás, masterépítés és
  karantén csak külön engedély és tételes megerősítés után fut.
- Közvetlen törlés nincs; a rendrakás visszavonható karantént használ.
- Az ingest-, időjárás- és live-night automatizálás csak nyitott app mellett
  működik. Ez a béta nem telepít háttérfolyamatot.
- A felhőzet-előrejelzés külön opt-in, és csak akkor küld kerekített
  helyadatot az Open-Meteónak, ha bekapcsolod.
- macOS 26 vagy újabb szükséges. Az app és a CLI Universal bináris
  (Apple silicon + Intel), Developer ID-val aláírva és Apple által
  notarizálva kerül a GitHub release-be.

## Telepítés

1. Töltsd le az `AstroTool-3.0.0-beta.1.dmg` fájlt.
2. Ellenőrizd a letöltést a mellékelt `SHA256SUMS.txt` alapján.
3. Húzd az AstroTool alkalmazást az Applications mappába.
4. Az első V3 futást read-only módban végezd, és csak ellenőrzött előnézet
   után engedélyezz könyvtármutációt.
