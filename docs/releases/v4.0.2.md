# AstroTool 4.0.2

Ez a V4 második hotfix kiadása. A 4.0.0 funkciói változatlanok; a kiadás a
natív mappaválasztó után megjelenő első beolvasási összegzés lezárását javítja.

## Javítás

- A **Tovább a könyvtárhoz** gomb biztosan bezárja az összegző lapot, és
  megnyitja a képkönyvtárat.
- A mappaválasztó után következő lap csak az előző modális lap teljes
  bezárása után nyílik meg, így nem marad hibás prezentációs állapotban.
- A sikeres belépés elmenti, hogy az első lépések befejeződtek.

## Telepítés

1. Töltsd le az `AstroTool-4.0.2.dmg` fájlt.
2. Ellenőrizd a letöltést a mellékelt `SHA256SUMS.txt` alapján.
3. Nyisd meg a lemezképet, és húzd az AstroTool appot az Applications mappába.

Rendszerkövetelmény: macOS 26 vagy újabb. Az alkalmazás és a CLI Universal
bináris. A publikus csomag Developer ID aláírással és Apple-notarizációval
készül.

Hibajelentés: [GitHub Issues](https://github.com/themokx1/Astro-Tool/issues)
