# AstroTool v5.0.0 prototype — Wave 1 release evidence

State: **NOT RELEASED.** This document collects the Wave 1 gate evidence. The
prototype may be called ready for own-device trial only when every section
below is filled with a pass, including the external gates.

## Scope

Offline iPhone companion exchanging an encrypted `.astromobile` AirDrop
document with the Mac. The Mac remains the sole owner of the photo library;
only checklist completions and notes return from the phone; no CloudKit,
TestFlight, or background execution; Personal Team install with the seven-day
provisioning limit.
